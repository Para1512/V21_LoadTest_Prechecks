Results Preparation

Collate Tuxedo stats and build resource utilization after the load test.

PreChecks window

Collate results

Enter the test window. The portal collects the NPE report, lists any response times above 10 sec for each server so you can correct them, then builds the PET Enhanced online report (oln_report.txt) and API report (api_report.txt).

Use the clock picker to select the test times. Collection can take a couple of minutes.

Processing

    Resource utilization

    Upload the Dynatrace dashboard PDF. The portal builds RU_Stats.csv for the CSM online, PRAPI, ESB CL, and ESB DG servers only.

    The report name is the first row. Text before the first _ is used on the section titles, so R1226_Reg_LoadTest produces R1226 CSM OL PET1.
